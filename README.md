# CraftLink – Quản lý listing

## 1. Giới thiệu
CraftLink là giao diện hỗ trợ người bán quản lý các sản phẩm thủ công và theo dõi trạng thái sản phẩm trong gian hàng.

## 2. Trang thực hiện
Quản lý listing.

## 3. Chức năng chính
- Hiển thị danh sách sản phẩm.
- Tìm kiếm sản phẩm theo tên.
- Lọc sản phẩm theo trạng thái.
- Chuyển đổi giữa chế độ bảng và lưới.
- Thêm sản phẩm mới.
- Chỉnh sửa thông tin sản phẩm.
- Lưu trữ sản phẩm.
- Xem thông tin thống kê mẫu.
- Hiển thị trạng thái đang tải và danh sách trống.

## 4. Công nghệ sử dụng
- HTML: Xây dựng cấu trúc trang.
- CSS: Thiết kế giao diện và hỗ trợ hiển thị trên điện thoại.
- JavaScript: Xử lý các chức năng tương tác.
- Tailwind CSS và Lucide: Thư viện hỗ trợ giao diện.

## 5. Cách chạy
Mở file `listing.html` bằng trình duyệt để xem giao diện.
